БИРМИНГЕМ: ЦЕНА ВЛАСТИ — v1.4 «ПЕРВОЕ ДЕЛО»

Откройте index.html в браузере или через Live Server в Cursor.
На главной странице: ДЕЛА ГОРОДА → СМОЛЛ-ХИТ → ОТКРЫТЬ ДЕЛО.

«Долг, который не прощают» — самостоятельный интерактивный сюжетный прототип:
28 сцен, 5 концовок, улики, условия выбора, ветвления, автоматическое сохранение в localStorage.
Перезапуск дела: кнопка «Начать дело заново».
Покинуть дело можно через «Карта города» — прогресс сохраняется.

Квестовый прогресс хранится отдельно: birmingham_case_smol_heath_v1.
Статистика викторины хранится по прежнему ключу и не изменена.
Остальные четыре района — пока анонсы, а не готовые квесты.

Это первая самостоятельная история и фундамент будущего движка. Диалоги пока текстовые, без озвучки и постановочных иллюстраций для каждой сцены. Прохождение и баланс всех ветвей требуют дополнительного тестирования на устройствах.
