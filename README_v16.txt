v1.6 — ИСПРАВЛЕНИЕ СЮЖЕТНОГО ИНТЕРФЕЙСА

1. Убрано дублирование повествования: верхняя панель диалога показывается только в сценах с настоящей репликой персонажа. В остальных сценах остаётся единый текст обстоятельств и решения.
2. Уменьшена высота большой картинки, заголовок больше не занимает весь экран.
3. Для Рида, Крейна и Артура добавлены отдельные небольшие портретные изображения из исходного художественного материала; это временные изображения, пока не появятся полноценные авторские портреты.
4. Обработаны исходные иллюстрации; исходное разрешение не увеличено.
5. Механика расследования и сохранения не менялись.
