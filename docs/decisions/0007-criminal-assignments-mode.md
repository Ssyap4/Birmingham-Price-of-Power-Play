# ADR-0007 — отдельный режим «Криминальные дела» и его приоритет

**Дата:** 2026-11-16. **Статус:** accepted (автор поддержал концепцию отдельного криминального направления; производственную очередность выбрал ведущий разработчик).  
**Область:** будущий новый режим, карта поручений, мобильный интерфейс, дальнейший roadmap.  
**Подробности:** [Производственный паспорт](../criminal-operations/README.md).

## Контекст

Детективная кампания включает работающие Дела №001 и №002, но другие районы основной карты ещё ждут собственных сюжетов. Автор предложил пять **не-детективных** криминальных поручений для пяти членов ближнего круга: разные районы, разные задания, высокий риск ранения и гибели, случайные события и найденные предметы. Существующую карту нельзя превращать в перегруженный набор неродственных точек.

## Решение

1. Новый верхнеуровневый пункт **«Криминальные дела»** и отдельная карта с пятью историческими районами; пять персонажей = пять самостоятельных поручений.
2. Общий изолированный движок с HP, ресурсами, ограниченными предметами, боевыми/социальными/маршрутными решениями и фиксируемой случайностью. Цель каждой истории — выполнить приказ **и выжить**.
3. Режим отделён от дедуктивных 001/002: не изменять их графы, движки, хранение, достижения, канон, исходы или карту.
4. Смерть не стирает героя из других режимов. Отдельное сохранение попытки, исхода, риска; награды по уникальному результату — только после проверки сохранения и без повторной выдачи.
5. **Очередь:** устранить подтверждённые блокирующие проблемы объединённой беты; затем сделать один полноценный вертикальный CR01 со всеми базовыми системами; расширить CR02–CR05. **Не ждать**, пока будут разработаны остальные три детективных района. Детективное расширение остаётся отдельной будущей веткой.
6. Mobile-first: вертикальный iPhone/Android → Telegram WebView; не тратить самостоятельное время на ПК, клавиатуру, landscape.

## Последствия

- Требуется самостоятельная архитектура случайности, автосохранения, боевой экономики и баланса смертности; без заведомо гарантированных побед/поражений и бесплатных повторных бросков через reload.
- Пять поручений должны отличаться содержанием и интерактивными системами, не только визуалом.
- Названия и география пока **предварительные**; перед рисованием отдельной карты проверить соответствие эпохе. Бренд и персонажей защищённого сериала в публичный UI напрямую не переносить.
- На этом коммите утверждён только **производственный план, не реализация**. Никаких изменений игры, save keys, `main` и Safari-preview.
