# ADR-0005 — Дело №002: мобильные кадры без обязательного landscape master

**Дата:** 2026-11-14. **Статус:** accepted. **Дополняет:** ADR-0003 и ADR-0004.

## Решение

1. **Игра проектируется для вертикального телефона и будущей Telegram Mini App.** В новых художественных партиях только отдельные вертикальные WebP — никаких дополнительных горизонтальных мастеров и работы по их доработке. Уже утверждённые P01–B05 остаются в исходном виде.
2. `mobileOnly:true` позволяет использовать канонический `file` как идентификатор сцены, при этом физически хранится только `mobileFile`, его размеры и SHA-256. Нельзя ссылаться на несуществующий landscape и нельзя замаскировать отсутствие реального WebP фиктивным манифестом.
3. На общих изображениях не показывать **выбираемого игрового героя** как конкретного мужчину или женщину. У игры есть пять героев, включая Элеонору; использование мужского силуэта вместо всех противоречит сценарию. Допустимы NPC, предметные кадры, документы без вымышленных фактов и нейтральная точка зрения.
4. Для B06 нужна сломанная грузовая пломба возле двух колей телеги; B07 — пустая старая котельная с мокрой женской перчаткой и жестянкой чая, **без людей**; B08 — заводской вахтёр при проверке пропуска; B09 — чужие имена в платёжной книге и изношенные руки рабочего; B10 — исправленная строка о клапане в акте Мерсера, **не выдуманный коммерческий договор**.
5. Генератору ставить задачу **один конкретный эпизод — одна самостоятельная композиция**. Нельзя принимать многосценные коллажи, рамки с подписями, неверных NPC, выдуманные улики. Ошибки отбраковывает разработчик без привлечения автора к повседневному согласованию.
6. Все созданные, визуально принятые, оптимизированные кадры **одной полной художественной волны** загружаются вместе с игровым манифестом одной транзакцией. Не создавать коммит после каждого изображения.
7. Только адресные художественные/мобильные тесты при иллюстрациях; глубокий сюжетный QA при изменениях логики или релизе.

## Обратная совместимость

Рендерер поддерживает как исторические landscape+mobile файлы, так и мобильный оригинал без широкого файла. Если исходник повреждён, UI остаётся доступным. Сохранения, хронология и геймплей не меняются.
