## Правило новых решений

Когда меняется не отдельный цвет или фраза, а **принцип** (структура папок, API между модулями, формат сохранений, схема публикации, правила выдачи наград, безопасность художественных ресурсов), добавить следующий номерной файл вида `0004-short-title.md` со следующими разделами:

1. **Дата, статус:** proposed / accepted / superseded и ссылкой на замену.
2. **Контекст:** наблюдаемая проблема, какие файлы и ветки затрагивает.
3. **Решение:** что конкретно принято и чего не делаем.
4. **Последствия:** совместимость, миграции, тесты, минусы.
5. **Доказательства:** ссылки на коммит, тест, сценарий или технический документ.

Не переписывать принятое историческое решение молча: если подход меняется, создать новый ADR со ссылкой на старый. Секреты и пользовательские личные данные в публичный GitHub не загружать.
