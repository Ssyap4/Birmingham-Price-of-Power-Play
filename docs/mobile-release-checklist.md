# Мобильная приёмка — первый стабильный релиз Дела №001

## Целевая платформа
- В первую очередь вертикальный Safari на iPhone и мобильные Android-браузеры; Telegram Mini App — следующая упаковка того же веб-интерфейса.
- Тестовые ширины: 320×700, 375×812, 390×844 и 430×932 CSS px, а также реальные размеры iPhone с safe areas.
- Горизонтальный режим поддерживается как дополнительный, но никогда не навязывается игроку. Не используем принудительную блокировку ориентации.
- HTML работает как самостоятельный сайт на HTTPS GitHub Pages. Локальный index.html сохранён для отладки на компьютере.

## Блокирующие критерии перед релизом
1. Утверждённое иллюстрированное главное меню и пять отдельных кнопок работают без перекрытий, обрезки или повторного наложения HTML-текста на надписи картинок.
2. Карта пяти районов, выбор пяти персонажей, переходы на карту, в расследование и назад сохраняют рабочие состояния.
3. Короткое обучение Дела №001 появляется перед новой попыткой, предлагает четыре пункта, не блокирует сохранённую игру, открывается повторно по желанию и не перекрывается выбором героя.
4. Длинные диалоги, текст сцены и все варианты решений читаются при ширине 320 CSS px. Портреты не пересекаются с текстом.
5. Инвентарь с 11 уликами, результаты дедукции, все шесть концовок и последние строки финальных отчётов прокручиваются и остаются видимыми на iPhone.
6. Кнопки музыки, эффектов и выхода в расследовании расположены в потоке страницы и не заслоняют повествование. Целевые области нажатия не менее ~44 CSS px.
7. История прохождений изолирована по персонажам. Подтверждение выхода удаляет только текущую незавершённую попытку; отмена выхода и прогресс другого персонажа сохраняются.
8. В архиве ровно 18 сбалансированных достижений и 30 уникальных наград «дело × персонаж × концовка». Уже полученные награды не дублируются и не повторяют анимацию при загрузке.
9. Кинематографическая карточка достижения появляется только при новом открытии условия, не блокирует касания и отключает декоративные анимации в режиме reduced motion.
10. Никакой новой игровой механики, принудительной регистрации, внешних платных зависимостей или новых сюжетных сцен в рамках стабилизации первого этапа.

## Проверки
- GitHub Actions в публичном репозитории Ssyap4/Birmingham-Price-of-Power-Play, рабочий PR №1 и ветка feat/portrait-mobile-development.
- Быстрые проверки синтаксиса, файлов ресурсов и визуальной навигации; Chromium и WebKit.
- Полный прогон 154 исходных + 48 регрессионных = 202 сценариев после изменений логики, наград, сохранений и сюжетных переходов. Артефакт all-results.json должен показывать 202 успешных, 0 ошибок JS и 0 ошибок загрузки ресурсов.
- Скриншоты реальных состояний: меню, пять героев, карта, длинный диалог, заполненный инвентарь, дедукция, достижения, финалы и нижняя часть отчёта.
- Перед публикацией нужна ручная оценка Safari на настоящем iPhone, дополнительно к эмуляции WebKit.
- Стабильный публичный корень сайта обновляется только после приёмки; до этого актуальная тестовая версия размещается по /preview/mobile/.

## Репозитории и безопасность релиза
- Приватный Ssyap4/Birmingham-Price-of-Power — резервная копия, его два workflow отключены; не включать старую приватную публикацию, которая может перезаписать публичный main.
- Разработка идёт в публичном PR №1. Корневая стабильная версия игры и тестовый каталог /preview/mobile/ не должны подменять друг друга.
- Архивы и локальные награды не являются серверным профилем; регистрация, публичные профили и таблицы лидеров относятся к будущему этапу.
- Выпуск EXE/Electron/Tauri не планируется.
