# Мобильная приёмка — iPhone, Android, Telegram Mini App

## Основной режим
- Приоритетный способ запуска: HTTPS Telegram Mini App, затем обычный мобильный браузер. Локальный HTML сохранён для тестирования на компьютере.
- Интерфейс оптимизируем прежде всего под горизонтальный экран. Проверяем CSS-размеры 667×375, 812×375, 844×390, 915×412 и 932×430, а также более узкие устройства и safe areas.
- Telegram Bot API 8.0+: можно запросить fullscreen и **зафиксировать текущую ориентацию**. `lockOrientation()` не умеет поворачивать устройство из портретного режима в горизонтальный. На устройствах с разрешённым автоповоротом просим пользователя повернуть телефон, затем фиксируем горизонтальный режим.
- Обычные мобильные браузеры могут разрешить `screen.orientation.lock('landscape')` только после пользовательского действия и/или входа в полноэкранный режим. На iOS автоматический поворот через JavaScript ненадёжен; используем понятную подсказку, не CSS-имитацию вращения.

## Блокирующие критерии
1. Клавиши, важные для расследования, инвентаря и выхода, не перекрываются другими кнопками, уведомлениями, Telegram UI или системными вырезами.
2. Касания: целевой размер около 44 CSS px, понятное состояние фокуса, нет невидимых слоёв поверх активных кнопок.
3. Диалоги инвентаря и дедукции открываются в **видимой** части viewport, прокручиваются внутри окна, корректно закрываются и не прячут элементы под safe area.
4. На 5 этапах дела №001 отображаются разные, точно сопоставленные картинки из 37 утверждённых сцен.
5. Досье пяти героев, достижения и история прохождений работают независимо; одинаковый исход героя можно пройти повторно, но уникальная награда выдаётся только однажды на локальную запись.
6. В меню надписи из готовых иллюстраций нельзя перекрывать HTML-надписями; доступность кнопок обеспечивается `aria-label`.
7. Всплывающие уведомления о здоровье не перехватывают нажатия и скрываются при открытии модальных окон.
8. Сохранения и все 202 сюжетных/регрессионных маршрута дела №001 не меняются в рамках UX-правок.

## Автоматизация
- GitHub Actions: целостность файлов и статические тесты, Chromium навигация и клики, WebKit мобильные размеры, 202 сюжетных сценария при значимых изменениях.
- Скриншоты: главное меню, сюжетный экран, инвентарь, досье, достижения и архив. Одних зелёных тестов недостаточно: проводится визуальная ревизия.
- Тесты должны проверять присутствие и положение реальных элементов, в том числе перекрытия, а не только кликабельность.
- PR №17 не объединять в main до ручной приёмки. HTML/Telegram Mini App остаются целевой платформой; EXE/Electron/Tauri не используются.
