# V7 — Главное меню: профиль вместо настроек

Дата решения автора: 17 ноября 2026. Ветка: `feat/criminal-operations-polish-v3`.

## Утверждённая структура

**Два главных сюжетных направления, не шесть отдельных кнопок с делами:**
- «Детективные дела»: один общий вход, внутри дела №001/002 и будущие №003–005.
- «Работа для своих»: один общий вход в криминальную кампанию CR01–CR05.

**Второстепенные разделы:** «Испытания», «Достижения», «Досье персонажей», **«Профиль»**.

Автор отдельной поправкой потребовал **полностью убрать «Настройки» из главного меню**. Не возвращать вкладку или диалог настроек в последующих версиях, если не будет нового явного решения автора. Не путать личный **Профиль** и **Досье персонажей**: профиль отражает собственный прогресс игрока, досье — пять канонических героев.

## Ограничения

- **Это пока локальный профиль браузера, НЕ серверный аккаунт**; уникальный постоянный профиль, публичные награды и рейтинг — отдельная будущая инфраструктура.
- Не менялись `main`, существующая `preview/unified-campaign-safari` и старые сохранения.
- Текущая внешняя Safari-ссылка криминального режима использует закреплённый старый коммит и НЕ содержит обновлений меню/револьвера.
- Большой показ — после дальнейшей полировки и подготовки общей HTTPS-сборки, как пожелал автор.
- CI для текущих изменений: [GitHub Actions runs](https://github.com/Ssyap4/Birmingham-Price-of-Power-Play/actions/workflows/criminal-v2.yml). После проверки вписать **конкретный финальный успешный SHA**.
