## Сделано в этом пакете
Ранее объединённая HTML-сборка уже поддерживала детективные дела и криминальные операции. Однако открытый из главного меню общий архив `campaign-hub-v1.js` отображал только №001/№002.

Создан **`campaign-criminal-archive-v1.js`**, добавляемый через существующее событие `birmingham:campaign-render`, без изменения старых модулей. В общем архиве появляются три секции «Работа для своих»:
- **Достижения и награды:** ровно пять сворачиваемых карточек по миссиям, по четыре исхода каждая. Открытые исходы имеют названия подтверждённых знаков. Памятные достижения показываются только при реальном финале.
- **История прохождений:** восемь последних подтверждённых попыток, здоровье, число решений, отметка, первый ли это уникальный исход или повтор без новой награды. Полная хроника остаётся внутри режима.
- **Досье персонажей:** пять компактных карточек с количеством завершений и уникальных исходов. Не путать с личным «Профилем».
Из каждого раздела доступна реальная кнопка возвращения к карте «Работа для своих».

**Важно:** `CriminalArchive.ledger()` валидирует всю историю повторным проигрыванием и сверкой наград; новая проекция не вызывает `setItem`, `removeItem`, `recover`, не переписывает локальные ключи и не перезапускает побочные квесты. Если архив повреждён/недоступен, показывается предупреждение вместо вымышленных достижений. Стили — `campaign-criminal-archive-v1.css`, адаптивно для iPhone.
