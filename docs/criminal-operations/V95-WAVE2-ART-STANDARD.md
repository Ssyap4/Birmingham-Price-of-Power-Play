# V95 — художественный контракт второй волны (CR07–CR10)
Дата: 18.11.2026. Автор игры утвердил один автономный пакет Codex на одно поручение, затем отдельную приёмку ChatGPT. Стандарт общий, но задачи строго последовательные: CR07 → CR08 → CR09 → CR10. CR06 и более ранний арт не переделываются.

## Объём и формат
- Каждый пакет: ровно 20 самостоятельных сюжетных сцен + 4 разных финала, отдельные оригинальные кадры; финальные состояния задаёт движок, а изображения их не подменяют.
- Ориентация 4:5, финальный RGB WebP 720×900, без растяжения, лишних рамок, текста, водяных знаков, коллажей и процедурных заглушек. Генерировать крупнее с запасом кадрирования, уменьшить пропорционально. Штатный портрет героя — существующий assets/heroes/<heroId>.webp, его не заменять. Не переписывать сюжет ради картинки.
- Мобильная композиция: выразительный главный мотив в центральных 70–80%; важные детали не на самом краю. Не делать кадры одинаковыми: общий, средний, крупный план, интерьер, деталь, естественное изменение света/точки обзора. Не дублировать кадры путём кропа/рендера одного исходника. Лица NPC, гардероб, возраст, планировка и эпоха непротиворечивы; не использовать лица актёров или кадры сериала.
- Использовать только реально доступный инструмент оригинальной генерации. Если его нет или лимит исчерпан — сообщить, сохранить реально созданную часть; не заменять её SVG/Canvas/процедурной рисовкой, фотографиями из сети и не создавать ложные хеши/источник/статус. Для Codex разрешён пакет из 24 генераций, для обычных сообщений ChatGPT остаётся прежний протокол одного нового кадра.
- Жёсткий предел отдельного нового кадра: 256 KiB согласно deployment/criminal-package-budget.js. Целевой средний вес не более 160 KiB, сумма активных файлов одного пакета не более 3.75 MiB (3 932 160 байт); компрессия без размытия. Это рабочий бюджет V95, не повышать лимит всего unified (75 MiB). Текущая unified ~57.51 MiB; четыре пакета по 3.75 MiB дают ~72.51 MiB плюс небольшие изменения кода/манифеста, сохраняем резерв. При невозможности сохранить качество в бюджете — остановиться и сообщить фактические размеры, не повышать лимиты самостоятельно.
- Пока художественная приёмка не состоялась, файлы только assets/criminal/candidates/<mission lowercase>/<frameId>.webp. Не включать их в runtime-манифест. Не менять index.html, preview/criminal/index.html, exporters, engine, content, archive, epilogues, сохранения, награды, другие миссии и изображения. Отдельная ветка на базе проверенного HEAD; no main/merge/force-push/deploy. Принятый CR06 — визуальный эталон, не заготовка для дубликатов.

## Отчёт и честное доказательство
- Список действительных файлов, исходная генерация/провайдер (если доступна), sourceSha256 только по настоящим исходным байтам, sha256 WebP, git blob SHA-1, размер, width, height, exact sceneId, alt, краткое описание композиции, сведения о визуальной самопроверке. Если исходные байты получить нельзя, явно указать null и блокер; не выдумывать хеш. JSON в docs/criminal-operations/<MISSION>-ART-CANDIDATES.json, review: candidate. Никакого approved до независимого просмотра ChatGPT.
- Галерея <MISSION>-ART-GALLERY.html с 24 настоящими файлами x 720×900, заголовком sceneId, кратким описанием; локальная, без внешних ресурсов. Сценарные спойлеры разрешены внутри галереи. Не добавлять вымышленные пути к отсутствующим изображениям.

Убедиться, что git diff ограничивается кандидатами и их отчётами. Если не все готовы, статус partial, фактический список отсутствующих.
