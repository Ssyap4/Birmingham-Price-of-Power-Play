# V13 — Подготовительная ревизия общей навигации и архивов

Дата: 17.11.2026. Статус: **READ-ONLY AUDIT**. Это схема предстоящего комплексного изменения после успешного завершения мобильной QA V12, **не** утверждение о внедрённых исправлениях.

## Подтверждённая архитектура
- Активное главное меню: `cinema-home-v1.css` / `cinema-home-v1.js`, навигация по существующим DOM-ID `districtsCard`, `criminalEntry`, `data-mode="classic"`, `storyStart`, `profileCard`, `cabinetProfile`.
- Городская карта Дела №001/№002: существующие `#districts`, `campaign-map-journey-v1.js`, `case002-map-entry-v1.js`. Карта показывает прогресс отдельных героев и запускает конкретное дело; **эти механики не заменять дизайном**.
- Общие разделы архивов: `campaign-hub-v1.js` создаёт `campaignAchievements`, `campaignDossiers`, `campaignHistory` и их вкладки. `campaign-case002-archive-v1.js` добавляет подтверждённые результаты второго дела; `campaign-criminal-archive-v1.js` добавляет записи «Работы для своих» по read-only снимку. Данные авторитетны только в своих исходных хранилищах.
- `criminalEntry` открывает отдельную карту пяти поручений CR01–CR05. Не смешивать криминальные задания с пятью районами детективной карты.
- Музыкальные записи: `night-on-the-docks.mp3` и `menu-original.ogg`, три существующих фоновых OGG дел. Одно управление `bh-audio-controls`, один `audio-v1.js`.

## Конкретные найденные наследованные места
1. `deployment/campaign-unified-release.js` всё ещё перечисляет **все** корневые CSS/JS файлы при экспорте. Несмотря на отключение из активного `index.html`, устаревшие menu CSS/JS остаются внутри офлайнового пакета. До удаления из экспорта убедиться, что ни один другой HTML/тест их не импортирует; изменения только через белый список неиспользуемых меню-файлов.
2. `campaign-hub-v1.css` до сих пор содержит комментарий про музыкальное управление «в настройках кабинета», хотя кнопка «Настройки» удалена, а в меню появился музыкальный док. CSS при этом скрывает плавающий блок музыки в архиве и профиле — оценить мобильную доступность управления звуком, не допуская перекрытий архивных карточек.
3. У карт, архива и профиля разные исторические слои CSS и оформление возвратов. Следующий шаг — **единая вертикальная типографика, безопасные отступы Telegram, заголовки, сценарии возврата, состояния загрузки, прокрутка и упрощённый портретный UX**, не меняя движки и содержимое дел.
4. Проверять состояние после многократного входа/выхода `home → map → case → home`, `home → criminal → archive → home`, `home → achievements/dossier/profile → home`; отдельно 320/360/390/430 WebKit/Chromium. Экран не должен забывать положение/сохранение, дублировать обработчик, прятать кнопку возврата.
