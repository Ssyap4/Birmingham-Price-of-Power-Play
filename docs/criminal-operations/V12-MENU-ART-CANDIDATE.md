## Художественная приёмка

Портретная кинематографичная сцена без портретов реальных актёров, без фирменных знаков и без запечённых заголовков меню. Одна композиция: дождливое стекло ночного индустриального Бирмингема; стол с пустыми бумагами и сургучом, лампа, сигарный дым, настоящий граммофон. Верхняя часть пригодна для живой HTML-типографики, акцентные предметы не должны перекрываться шестью карточками (они ниже отдельной сцены). Изображение не подменяет проигрывание музыки.

## Адресная интеграция — только после установки WebP-байтов

1. Проверить контрольный SHA256 у файла в GitHub. **Не менять CSS до появления фактического WebP**.
2. Обновить `#home .cinema-art` в `cinema-home-v1.css` на установленный WebP, сохранив вертикальную геометрию `cover`. Из сцены убрать старую **рисованную CSS-подделку граммофона**, чтобы не было двух аппаратов поверх новой иллюстрации.
3. Перенастроить маску дождя на реальные оконные стёкла; свет лампы — с левой стороны кадра; дым — возле сигарного пепельника. Предпочесть лёгкие CSS-эффекты, отключаемые `prefers-reduced-motion`. Не создавать вторую музыкальную систему.
4. Сохранить обе мелодии меню `night-on-the-docks.mp3` + `menu-original.ogg`, три фоновых OGG дел, все ключи и существующий `#cinemaAudioDock`. Не менять действия `#districtsCard`, `#criminalEntry`, `data-mode="classic"`, `#storyStart`, `#profileCard`, `#cabinetProfile`.
5. Расширить адресный тест изображений: файл существует, декодируется, 720×900, заголовки читабельны на 320/360/390/430 px. Посмотреть реальные снимки WebKit/Chromium и только тогда считать установленным.
