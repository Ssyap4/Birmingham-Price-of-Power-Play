Отдельная пространственная SVG-карта с пятью районами, закреплённые герои, правила перед стартом, HP 0–100, расходники, сохранённая случайность, предметы, судьбы NPC, повторные попытки, самостоятельная хроника, именованные знаки и достижения.

Каждый сюжет имеет три акта. Следующие числа — результат реально выполненных **2000 синтетических прохождений на миссию**, seed 0…1999. Маршрут означает уникальную последовательность посещённых `sceneId`, без терминальной карточки. Это доказанный нижний предел числа маршрутов, а не обещание, что перечислены все комбинации, и не статистика живых игроков.

### Конкретные сюжетные различия

- **CR01:** `street → scout → backroom → yard → eli → stairs → oldDebt → decoy → handoff`. Разведанный двор и слово Лили позволяют обойти открытый бой; спасённый Илай уходит к Лили, а пустая сумка отвлекает Кейна. Иной путь через Ковелла позволяет отдать Илая в залог и сохранить портфель ценой тяжёлого исхода. После разведки теперь можно дополнительно встретить курьера за время: монеты во дворе достижимы честно.
- **CR02:** `fog → warehouse → locker → gangway → nora → deck → hold → ben → rescue → boat → quiet → seal → landing`. Свет даёт верный ящик, отвлечение капитана заменяет драку, освобождение Бена открывает лодочный проход. Путь по настилу ведёт к другой проверке верёвки и возможному падению в воду. Без ящика или после его утраты кнопка передачи не становится победой.
- **CR03:** `ball → ruth → cloak → library → photo → cabinet → original → discovery → ruthChoice → serviceExit`. Доверие и ключ позволяют взять подлинник без взлома и вывести Рут. При раннем подозрении документ перемещается в `conservatory`, где действуют другие условия. Можно отдать оригинал за Рут: это честный живой провал, даже если снимок остался.
- **CR04:** `prepare → garden → daniel → message → signal → negotiation → boughtTime → courier → watcher → fire → gardenExit → carSignal → evacuation → receipt`. Проверенный сигнал отличает помощь от подставы; удостоверение и деньги дают время; сад заменяет последний бой. Существует иной коридор через сделку с Беккером. При нуле здоровья Дэниела попытка сразу заканчивается живым провалом Виктора, без последующего разговора или эвакуации погибшего NPC.
- **CR05:** `route → market → passenger → harry → detour → lastRoad → friendGate → gate`. Длинная дорога, топливо и помощь Гарри открывают проход через Мину. Промышленная ветвь вместо этого проходит через поломку, ремонт и Фредди; быстрый путь — через преследование. Приёмка проверяет целый груз, машину, топливо и срок; пеший уход с частью партии победой не объявляется.

Генератор `image_gen.imagegen` действительно использовался. Один дополнительный запрос был отклонён фильтром; несуществующий результат не зарегистрирован.

В манифесте есть явная привязка каждого из 105 узлов и всех терминальных ID. Это **40 самостоятельных кадров**, разделяемых родственными сценами, а не 105 разных кадров. Четыре финала каждой миссии используют один нейтральный кадр пустой локации после ночи; двадцати отдельных финальных иллюстраций нет. Канонические герои показываются исходными портретами, не перерисованы.

Сборка: **43.35 MiB**, лимит 75 MiB соблюдён; 481 файл, 273 проверяемые статические ссылки. Контракт Дела №002 сохранён: **89 сцен / 102 одобренных сюжетных WebP / 10 NPC-портретов**; хеши оригиналов неизменны.

## Исправления по результатам самостоятельного анализа

1. Монеты у охранника двора были недостижимы вместе с разведкой — добавлен оплачиваемый временем дополнительный контакт с курьером.
2. Порог одного перехода по подозрению был выше достижимого раннего значения — скорректирован и подтверждён маршрутом с доверием Рут.
3. Прямой урон холодной воды мог убить раненого героя без специальной метки риска — теперь предупреждение учитывает и такой случай без броска.
4. Старые плавающие аудио/exit-контролы перекрывали карту — в новом режиме они помещены в поток страницы; в старых экранах остаются прежними.
5. Защищаемый NPC с нулём здоровья больше не попадает в последующие сцены живым — немедленный живой провал Виктора.
6. В тестовом коде устранены неоднозначный селектор двух кнопок хроники, некорректное восстановление mock-функции Storage и гонка проверки ещё не загруженного локального изображения. Неуспешный прогон не выдан за зелёный.
