Все шесть работ Kevin MacLeod имеют CC BY 4.0 на карточках автора; Moil (Ruskerdax) CC0 на OpenGameArt. Ссылки, лицензии и точные названия — assets/audio/soundtrack-v27.json. Требуется видимая атрибуция в игре, информация о перекодировании и сохранение credits при автономном экспорте.

Прямая загрузка из контейнера заблокирована DNS; отдельный read-only GitHub Actions workflow запрашивает исходники у автора/Commons, проверяет длительность, декодирует и перекодирует целые записи, формирует SHA-256 и артефакт. URL скачивания — кандидаты, не считать полученными до успешного CI. Рабочая версия пока использует прежний audio-v1.js и прежние файлы. Не переключать runtime на отсутствующие MP3. Новый playlist core уже реализует три изолированных shuffle-bag без повторения в пределах цикла и на границе, выбор по игровому контексту и equal-power кривую перехода. Он пока не подключён к HTML.

Следующий рабочий пакет: получить артефакт, проверить фактические файлы и авторство, установить все семь бинарных файлов вместе с метаданными, подключить к единому аудиодвижку с 3–4 с переходом (проверить WebAudio/iOS), незаметным управлением и прежними ключами bh_music_enabled / bh_effects_enabled. Случайная композиция при старте; смена контекста без перезапуска внутри того же режима. Case001 #caseGame; Case002 — отдельная страница preview/case002-prototype/index.html (отдельная точка подключения; будущие дела используют тот же детективный плейлист); #criminalScreen относится к криминальной линии. Проверить переходы, mute во время fade, отказ autoplay, hidden/background, экспорт, прямой HTML и WebKit.
