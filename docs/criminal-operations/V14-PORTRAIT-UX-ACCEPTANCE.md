# V14 — Портретная полировка карты и общего архива

Дата: 17.11.2026. Рабочая ветка: `feat/criminal-operations-polish-v3`.

## Проблемы, найденные по реальным V13 WebKit-снимкам
1. Карта «Детективные дела» в первые 250 мс окрашивалась в 35% непрозрачности целиком; первичный кадр был чрезмерно тёмным.
2. Плавающие музыкальные кнопки и дублирующее «ВЫХОД ИЗ ИГРЫ» закрывали рисунок выбранного района.
3. Вкладки общего архива занимали две строки даже на телефоне, а третья насильно растягивалась старым CSS.
4. На узком WebKit 320 px «Меню» в глобальной шапке сжималось до почти вертикального слова, а три счётчика Дела №001+002 разрывали подписи.

## Что реально внедрено
- `mobile-navigation-polish-v1.css`: карта и архив показываются **без анимации прозрачности всей страницы**; сюжетные игровые экраны оставили свои переходы. Метки районов контрастнее.
- `mobile-runtime-v1.js`: на детективной карте создан только один `#districtAudioDock`, в который перемещается **существующий** блок `.bh-audio-controls`. После выхода он возвращается в прежний режим (главное меню, body или штатная панель дела). Новых звуковых движков/аудиотегов/сохранений нет. «Выход из игры» скрыт внутри атласа и криминальной карты, где уже есть штатный безопасный выход; в Деле №001 собственное управление не тронуто.
- Архивные три вкладки выровнены в одну строку с 44+ px touch-целями; отменён старый `grid-column:1/-1` для третьей вкладки.
- При 320–355 px в глобальной шапке остаётся герб и полноценные кнопки «Профиль»/«Меню», вместо непонятных переносов. В сводке двух дел счётчики распределяются по двум колонкам с последним пунктом на всю ширину.
- Новая **отдельная короткая** проверка `.github/workflows/portrait-v14-smoke.yml`, не запускающая длинные криминальные playthrough-сценарии. Тесты `tests/portrait-v14-static.test.js` и `tests/portrait-v14-smoke.py` проверяют отсутствие изменений localStorage, реальное перемещение единственного аудиоблока, первую непрозрачную рамку карты, геометрию вкладок/шапки/счётчиков, маршрут карта → архив → криминальная карта → карта → главное меню.
