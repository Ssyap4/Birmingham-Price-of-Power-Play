# V13 — единые переходы между картами, архивами и профилем

Дата: 17.11.2026. Рабочая ветка: `feat/criminal-operations-polish-v3`.

## Внесено

- `campaign-bridge-v13.js` создаёт навигацию только на Детективной карте, на карте «Работа для своих», в трёх разделах общего архива и в профиле. Для реальных переходов используются прежние кнопки `districtsCard`, `criminalEntry`, `cabinetProfile` и `BirminghamCampaign.open`.
- Криминальная карта пересоздаётся при каждом открытии. Один `MutationObserver` добавляет переходы только при наличии `.cr-map`; во время игры, боёв и выбора реплик новая панель **не появляется**. Выход из криминального режима использует штатное `data-action="home"`, включая защиту несохранённого шага и очистку `body[data-criminal]`.
- `campaign-bridge-v13.css` выравнивает медно-тёмную палитру, границы карт, заголовки, отступы Safari и кнопки переходов. Ориентация — вертикальный телефон 320–430 px, без плавающих перекрытий.
- Общий архив раньше заявлял «только Дело №001», хотя дополнительные Case002/CR01–CR05 уже интегрированы. Текст обновлён: это один локальный архив трёх линий. Сами данные и счётчики каждого режима остаются авторитетными внутри исходных источников.
- Из `deployment/campaign-unified-release.js` исключены **ровно семь** старых неактивных кабинетных CSS/JS-файлов. Сами исходники в репозитории сохранены; перед исключением проверяется отсутствие их ссылок в активном `index.html`. Сюжетные модули не удаляются.
- Новый адресный `tests/criminal/unified-v13.test.js` проверяет статические контракты; `tests/criminal/mobile_browser.py` — реальную последовательность «детективная карта → общий архив → криминальная карта → детективная карта», отсутствие задвоений, доступ к профилю и сохранность игровых байтов.

## Границы

**Не менять** Case001, Case002, CR01–CR05, RNG, награды, localStorage и аудиосистему. Две оригинальные мелодии меню и три фоновых OGG сохранены. `main` и `preview/unified-campaign-safari` — без изменений; новая Safari-ссылка отдельно после приёмки большого пакета.

**QA:** сначала Node/проверка экспорта, затем один сквозной Chromium/WebKit только потому, что затронута общая навигация. Не объявлять SUCCESS до GitHub Actions и ручного просмотра мобильных скриншотов. Следующая рабочая волна — дальнейшая полировка архива и районных карточек, без добавления новых сюжетных механик.
