# Бирмингем: Цена власти — аудит «пустых карточек» после Досье 2.1

**Дата:** 13.11.2026. **Основа:** актуальные экраны и CSS `case001-briefing-v1.css`, `campaign-hub-v1.css`, `districts-v13.css`, `heroes-v1.css`, `case-v14.css`, `mobile-approved-menu-v1.css`.
**Принцип:** не заменять иллюстрациями работающие интерактивные элементы и не трогать ни одну из 37 сюжетных сцен / портретных привязок.

## Очередь на художественный проход

1. **Правила и сюжетное вступление Дела №001 — высокий приоритет.** Сейчас `.case001-briefing-panel` и пункты правил выполнены градиентами и рамками без предметной иллюстрации. Добавить обложку папки «Дело №001», сургучную печать и лёгкую фактуру бумаги *снаружи текста*. Условия и кнопки остаются настоящим HTML, а крупный текст не перекрывается.
2. **«История дел» — состояние без записей — высокий приоритет.** `renderHistory` выводит обычный абзац «Завершённых расследований пока нет». Вместо пустоты — запертый ящик архивной картотеки / папка «Записи отсутствуют» с читаемой подписью и ненавязчивой анимацией (или статикой при reduce-motion). После появления записей скрыть пустую сцену.
3. **«Достижения и награды» — заголовок и закрытая коллекция — средний.** `.campaign-head` чисто текстовый; `.campaign-award` использует геометрические карточки. Усилить *заголовок* витриной старинных знаков/медалей и осторожно добавить фоновую гравировку для пустой коллекции. **Не** дублировать 18 достижений / 30 знаков в профиле.
4. **Будущие районы без доступного дела — средний.** На карте районы уже имеют изображения и иконки. Не менять карту и фотографии. Добавить лишь «запечатанную папку будущего дела» под описанием недоступного района, без имитации доступной кнопки расследования.
5. **Досье пяти героев — низкий.** Портреты уже крупные и художественные (`.campaign-portrait`). При желании можно оживить только общую архивную шапку, добавить фактуру фотографической картотеки. **Нельзя** менять утверждённые портреты или изображать новые персонажи поверх них.

## Уже хорошо — не переделывать
- **Дело №001:** `.case-art` и таблица `ART` — индивидуальная сценическая иллюстрация, нет «пустых» сцен, не затрагивать.
- **Выбор героя:** фотографии с утверждёнными портретами; не заменять картинками повторно.
- **Главное меню:** утверждённые изображения каждой кнопки; точечная замена «Настроек» на «Моё досье», без пересборки остальных.
- **Карта районов:** оригинальные фоны, SVG иконки, уже принятая мобильная навигация; не создавать картинок ради декора.

## Правила внедрения
- Сначала отдельный визуальный пакет (новые CSS + ассеты), затем целевые Chromium и WebKit проверки на 375×812, 390×844 и desktop.
- Крупный текст всегда над затемняющей подложкой, интерактивные кнопки — настоящие DOM-элементы.
- При старом/повреждённом кэше фон может не загрузиться, но раздел остаётся полностью функциональным.
- Не трогать сюжетные концовки, логику находок, сохранения и таблицы `ART` / `ACTORS`.
- Не переносить художественный проход в стабильный `main` без отдельной приёмки на iPhone.
