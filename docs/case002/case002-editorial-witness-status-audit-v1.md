# Дело №002 — редакторская проверка статусов свидетелей

Исходная рабочая ветка: `feat/case002-story-bible-v1`, HEAD `2ad6866b47a3cbb1655c479eb061eac1d40d2798`. Все 89 основные сцены имеют установленный арт; это отдельная редакторская полировка, а не релизная приёмка.

## Исправления

Динамические сводки выводили **Аду Уэбб** с мужскими формами: «найден», «вывезен», «погиб». Добавлена общая функция `witnessStatus(id,status)`, которая выдаёт корректные женские формы для Ады и мужские — для Томми и Мерсера.

Статус `detained` раньше подписывался «под охраной» — его можно было спутать с `protected` («под защитой»). Теперь текст однозначен: «задержан/задержана **частной охраной**». Это описывает принудительное удержание и не подразумевает безопасность.

В `tests/case002/story-variants-v4.test.js` проверяются **216** сочетаний трёх свидетелей, шести канонических статусов и двенадцати промежуточных/итоговых сцен, включая семь концовок. Существующие 35 реальных маршрутов по пяти героям и семи исходам сохранены.

## Визуальные границы

- При задержанной Аде в D02, D03 и HE02 её иллюстрация намеренно не подставляется: не изображать отсутствующего свидетеля.
- Z02 имеет отдельные файлы для состояния без эвакуированных и семи вариантов с одним или несколькими вывезенными; рисунок не определяет судьбу людей, это делает игровое состояние.
- Для всех героев действуют индивидуальные сценические кадры; 89/89 означает первичное художественное покрытие, а не завершение полировки всех вариаций.
