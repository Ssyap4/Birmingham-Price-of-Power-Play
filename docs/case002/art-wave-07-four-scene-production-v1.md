Скрипт `install_wave.py` испытан на **временном тестовом репозитории** с тем же форматом `approved-art-v1.js`: завершился с кодом 0, добавил ровно P02/A02/A10/B03 и скопировал ровно 8 WebP; P01 осталась одной записью. Это **тест установщика**, а не реальный GitHub commit или полноценный browser smoke.

В текущем окружении прямой доступ локального контейнера к GitHub по Git отсутствует, а доступный GitHub-коннектор не принимает путь к ZIP как бинарную загрузку. Поэтому новая рабочая ветка по-прежнему **12/16**, ни один из восьми бинарных файлов не опубликован. Не коммитить манифест отдельно от файлов — он немедленно нарушит художественный аудит.
