# Волна 18 · Глава IV · D01–D05 — старт художественного производства

Сверено с оригинальным `case002-screenplay-acts-4-6-and-endings-v2.md`, раскадровкой `case002-art-storyboard-v1.json` и утверждённым манифестом. Протокол остаётся один: **«Один кадр — один сюжетный момент»**. Для каждого ID используется индивидуальная карточка в `art-wave-18-shotcards-v1.json`, RENDER и REVIEW раздельны. Сценарные ветви и флаги не изменялись.

## Кадры в правильном порядке
- **D01 «Три разных страха»** — развилка с тремя адресами в кабинете сыщика, без утверждений о судьбах свидетелей. Создан физический **кандидат** `assets/case002/candidates/case002-d01-scene--mobile.webp`: WebP 720×900, 116020 байт, SHA-256 `dd5a2469746898d6564f02a862944ebb81347c81b5937e0c867bc3ae9bc97206`, Git Blob SHA-1 `ad4d9778925572143f436ebad0c46a2004e55dd8`. Первая художественная оценка: три адресные карточки, дождливый город, лампа; нет читаемых имён и статусов. Только CANDIDATE, **не утверждённое игровое изображение**.
- **D02 «Ада в котельной»** — недоверие, гаечный ключ, холодная решётка. Две попытки в текущем контексте ушли к старым железнодорожным эпизодам. **REJECTED, не использовать**. Лицо Ады нужно сверять с `case002-ada-portrait.webp`; допускается съёмка со спины/обрезка лица.
- **D03 «Журнал давления»** — исходный журнал остаётся у Ады, игрок может получить копию только при сценарном условии. NOT STARTED.
- **D04 «Томми за воротами»** — удерживаемый Томми, повязка, охрана; лицо только по утверждённому `case002-tommy-portrait.webp` или в тени. NOT STARTED.
- **D05 «Цена доступа»** — охранник, сменщик и водитель при служебном выходе до выбора маршрута; без победы и обещания спасения. NOT STARTED.

## Порядок дальнейших действий
1. Продолжить **не** текущим загрязнённым художественным контекстом. В новой чистой визуальной постановке начинать с единственного RENDER D02 из `art-wave-18-shotcards-v1.json`; D03–D05 рисовать только раздельными запросами.
2. REVIEW для D02/D03/D04 проверяет каноническую внешность NPC и статусы свидетелей. Не генерировать персонажей выбора от имени игрока.
3. По готовности всех пяти сцен физически декодировать, проверить размеры, SHA-256/dHash, затем атомарно установить в `assets/case002/scenes/` и `src/case002/approved-art-v1.js`; до этого никаких `review:"approved"` записей.
4. После установки выполнить адресные art-тесты и короткий мобильный Chromium. Тяжёлые сценарные проверки без изменения логики не требуются.
5. Не касаться `main` или Дела №001.
