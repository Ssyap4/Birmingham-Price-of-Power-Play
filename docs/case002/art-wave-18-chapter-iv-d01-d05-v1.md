Возобновлять генерацию только из нового художественного контекста по одному RENDER, без сообщений о разработке и отчётности.

Крупные планы рук и силуэтов предотвращают подмену канонических внешностей героев. **Это только техническая подготовка: ни один H-кадр пока не нарисован и не утверждён.** Волны по 4–6 изображений могут устанавливаться отдельно; запрет преждевременно выдавать главу целиком остаётся.
