# Дело №002 — визуальная библия v1
**Этап:** подготовка производства, **без сгенерированных изображений**. Вплоть до завершения сюжетного тестирования никакой готовый арт не добавляется в игру. Основная визуальная преемственность — утверждённые noir-панели и кинематографические сцены Дела №001; персонажи нового дела должны быть оригинальными, не копировать внешность актёров известных сериалов.

## Режиссура, цвет, телефон
Камера должна рассказывать **то, что герой действительно знает в этот момент**. При неизвестной личности убийцы — только силуэт, сапог, голос за рамой. При найденной улике — кадр на происхождение и контекст предмета; нельзя рисовать документы с выдуманной решающей подписью, если она ещё не установлена.
Гамма: золото керосиновых ламп, холодный серо-синий туман, черно-коричневая угольная пыль, мокрая кирпичная кладка. Красный — редкий акцент опасности, не интерфейсная подсветка по умолчанию. Источники света реальные: газовый фонарь, окно конторы, фабричная лампа, освещённый проход. Без глянцевого steampunk и бесконечных ярких вспышек.
Каждой сцене назначен **уникальный кадр** в `case002-art-storyboard-v1.json`; допускаются повторно используемые исходные декорации/предметы, но ракурс, действие и композиция должны менять смысл. Портреты персонажей — отдельный согласованный единый набор, не «новое лицо» при каждой реплике. Исторический стиль в самостоятельной авторской интерпретации.
Генерировать мастер 16:9 высокого качества и оригинальный вертикальный кроп для телефонного показа; не просто растягивать горизонтальную картинку до 9:16. Держать ключевые лица и предметы в безопасной центральной области, не прятать их под верхней строкой дела, нижней панелью имени или кнопками Telegram. На 360–430 CSS px проверять резкость текстур и различимость лица. Сами реплики и элементы управления — HTML, а не текст внутри изображения. Итоговые изображения оптимизировать в WebP, без артефактов тонких золотых рамок.
Никаких новых интерфейсных рамок без нужды: использовать единый утверждённый язык золотой окантовки, тёмного фона, тиснения и типографики.

## Производственный порядок
1. Утвердить сюжетную матрицу и закрыть ошибки движка.
2. Создать reference sheets для новых персонажей и проверить совпадение внешности в портретах.
3. Утвердить постоянные декорации всех локаций в рамках общей стилистики Дела №001.
4. По `case002-art-storyboard-v1.json` создавать отдельные кадры для каждого из 89 эпизодов; условные варианты — отдельные файлы с `variantId`. Иллюстрацию не добавлять как обязательное условие расследования.
5. Сгенерировать предметные иконки и портреты, проверить их независимые файлы и правильную ориентацию на телефоне.
6. Проверить соответствие каждый кадр ↔ sceneId ↔ условия движка ↔ телефонный кроп, мобильную производительность, читаемость и отсутствие растяжения.
7. После качественной проверки сформировать **крупную** тестовую публикацию, без промежуточных мелких ZIP.

Пользователь разрешил автору **самостоятельное художественное решение без согласования каждого кадра**. Но разрешение не означает, что уже созданные изображения можно выдавать за утверждённые: в этом пакете пока только рабочие задания.
