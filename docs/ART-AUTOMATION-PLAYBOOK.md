# АВТОМАТИЧЕСКАЯ ЗАГРУЗКА АРТА — проверенный постоянный playbook

**Канон проекта «Бирмингем: Цена власти». Обновлено 17.11.2026.**
**Важнейшее правило автора:** ассистент делает ВСЁ сам. Пользователь **никогда** не загружает вручную WebP, архивы, картинки, манифесты или ассеты в GitHub. Не предлагать ручную загрузку, если доступен проверенный путь ниже. Точность обещаний: заявлять «встроено в игру» только после фактической установки двоичных байтов в репозиторий и обновления ссылок, а не после создания локального кандидата.

## Неприкосновенные правила

- **Одна генерация одной новой иллюстрации на одно пользовательское сообщение**; после неё художественная проверка и самостоятельная обработка/интеграция; вторую генерацию в том же ходе не начинать даже после брака.
- Кадр = один сюжетный момент, а не одна улика. Для игровых персонажей использовать утверждённый канон внешности. Для декора меню, карт и интерфейсов можно использовать подходящие изображения, но не рисовать в них «запечённые» UI-надписи.
- Вертикальный телефон / Telegram Mini App; WebP 720×900 — утверждённый формат вертикальных художественных кадров, когда назначение требует такой размер; не растягивать иллюстрации.
- Рабочую ветку и свежий HEAD определить перед каждым записывающим действием. Без согласия **не** менять `main` и `preview/unified-campaign-safari`, не править Case001/Case002/CR01–CR05, сохранения/движки и выдачу наград ради картинки.
- Без необходимости не запускать дорогие сквозные сценарные проверки. **Адресный art/DOM/mobile QA**, а полная матрица только если фактически менялись общая навигация, сборка или другие критичные общие компоненты.

## Проверенный автоматический бинарный маршрут (не теория — V12 установлен)

1. Сгенерировать **ровно одно** изображение и сверить его с утверждённой сценой. Пригодное изображение можно привести к WebP 720×900 с Pillow; проверить режим RGB, реальные размеры и успешное декодирование, получить `SHA-256`, количество байтов, **Git Blob SHA-1** с заголовком `blob <number_of_bytes>\0`.
2. Локально закодировать фактические байты WebP в base64 и передать в доступный контекст инструментов. Если работающий GitHub-коннектор не имеет команды для двоичных загрузок, использовать подтверждённую связку: временный текстовый base64-файл → `files__manage_library` (upload во временную Library-папку) → `files__read` в `functions.exec` по последовательным диапазонам строк, например 800 + 800 + остаток → склеить строки в JS → удалить пробелы/переводы строк → проверить длину и допустимые символы base64. Данные НЕ переносить вручную через ответ пользователю и не заменять ими весь HTML.
3. В `functions.exec` вызвать `tools.mcp__GitHub__create_blob({repository_full_name: "Ssyap4/Birmingham-Price-of-Power-Play", content: b64, encoding: "base64"})`; **сверить SHA Git object** с рассчитанным Git Blob SHA-1 для исходных байтов. При несовпадении **остановиться**, не коммитить.
4. Получить текущий ref ветки и родительский tree. Вызвать `create_tree` с `base_tree_sha` и элементом вида `{path:"assets/…/image.webp",mode:"100644",type:"blob",sha:"<verified blob SHA>"}`, затем `create_commit` с `parent_sha` и `tree_sha`, и наконец `update_ref` с `expected_sha`. Проверить, что ветка не сдвинулась; при конфликте не делать force-push. На этом шаге WebP **реально существует в GitHub**.
5. Только после этого установить путь в активный CSS/HTML, или добавить согласованную запись в approved-art manifest по правилам конкретной сцены. Не писать несуществующий URL в игру и не выдавать Library-кандидата за установленный ассет. Обновлять адресные Node-тесты: наличие файла, точный размер, WEBP RIFF, SHA-256 и отсутствие дублирующих элементов, плюс браузерный декодер и скриншоты на целевых ширинах.
6. Убедиться в реальной успешности CI/проверенных снимках, сохранить финальный игровой SHA и отдельный HEAD документации. Удалить временный base64-транспорт из Library после установки, сохранить утверждённый WebP-кандидат/оригинал при необходимости. Ничего не публиковать на Safari/main без согласованной приёмки.

Если прямой binary-tool в будущем снова станет доступен, им можно заменить временный base64-транспорт, **но** сохранять проверку контрольной суммы, отдельный commit и условия защиты веток.
